# 触控与触控板手势

本项目的桌面针对触摸屏和键盘保护套的触控板加了一组手势。窗口和工作区相关的手势来自 Niri 补丁（[`niri/patches/`](../niri/patches/)），顶栏、控制中心、锁屏和屏幕键盘的手势来自 [`desktop-rust/`](../desktop-rust/)。没有打补丁的原版 Niri 只有下文标注为 Niri 自带的那部分。

## 触摸屏

### 总览、列和工作区

三根或更多手指同时操作：

| 手势 | 作用 |
|---|---|
| 捏合 | 打开总览 |
| 在总览中张开 | 关闭总览；张开时手指在某个窗口上，就切换到这个窗口 |
| 横向滑动 | 左右滚动窗口列 |
| 纵向滑动 | 切换工作区 |

手势跟随手指移动，抬起任意一根手指即结束，松手后带惯性回弹。手势开始后，这次触摸不再传给应用。

### 窗口

每个窗口顶部中间有一个胶囊形的把手：

| 操作 | 作用 |
|---|---|
| 轻点把手 | 打开窗口菜单 |
| 拖动把手 | 移动窗口，不需要按住键盘上的 `Super` 键 |
| 把窗口拖到另一个窗口的下半部 | 和该窗口叠放在同一列 |
| 拖动两列之间的缝隙 | 同时调整两列的宽度，在 1/3、1/2、2/3 处有吸附 |
| 双击两列之间的缝隙 | 两列恢复各占一半 |
| 拖动单独一列的外侧边缘 | 调整这一列的宽度 |
| 拖动同一列中上下窗口之间的缝隙 | 调整上下窗口的高度 |
| 拖动浮动窗口的边框或四角 | 调整浮动窗口的大小 |

### 顶栏和控制台

| 操作 | 作用 |
|---|---|
| 从顶栏左半边或右半边向下拉 | 拉出控制台：控制中心在下拉的那一侧，通知在另一侧，中间是应用菜单 |
| 在控制台底部或空白处向上滑 | 收起控制台 |
| 轻点通知横幅 | 打开对应应用 |
| 向上滑通知横幅 | 关闭这条通知 |

控制台跟随手指拉动，松手时按速度和位置决定展开或收回。顶栏正中间的区域不触发下拉。

### 锁屏

轻点锁屏界面显示密码输入；输入时会弹出锁屏自带的屏幕键盘。

### 屏幕键盘

| 操作 | 作用 |
|---|---|
| 双指捏合 | 停靠或分裂形态切换为悬浮形态 |
| 双指张开 | 悬浮形态切换回停靠形态 |
| 拖动悬浮键盘底部的横条 | 移动悬浮键盘 |
| 长按字母键 | 选择候选字符 |
| 长按删除键 | 连续删除 |
| 在空格键上左右滑动 | 移动光标 |
| 在按键上向上滑 | 输入按键上标注的符号 |

后两项默认开启，可以在键盘的工具箱里关闭。

### 系统设置

窗口较窄、只显示一栏时，从左边缘向右滑返回上一级。

## 触控板

触控板使用 libinput，默认开启轻触点击和自然滚动：

| 手势 | 作用 |
|---|---|
| 单指轻触 | 左键点击（Niri 自带） |
| 双指轻触，或按下触控板右下角 | 右键点击（Niri 自带） |
| 轻触后立即按住拖动 | 拖动（Niri 自带） |
| 双指滑动 | 滚动（Niri 自带） |
| 三指横向滑动 | 左右滚动窗口列（Niri 自带） |
| 三指纵向滑动 | 切换工作区（Niri 自带）；控制台打开时，三指上推收起控制台 |
| 三指或更多手指捏合 | 打开或关闭总览；总览打开时双指捏合也可以 |
| 双指从触控板上边缘向下滑 | 拉出控制台，光标在屏幕上的什么位置都可以 |
| 光标在顶栏上时双指向下滑 | 拉出控制台 |
| 控制台打开时双指向上滑 | 收起控制台 |
| 锁屏时双指向上滑 | 显示密码输入 |

键盘保护套的触控板面积较小，原版 Niri 的四指纵向滑动（打开总览）已经关闭，改用捏合。

打字时触控板会暂时停用，避免手掌误触。键盘保护套翻折到背面后，触控板完全停用。

## 键盘快捷键

完整列表可以按 `Super+Shift+/` 查看。和桌面组件相关的几个：

| 快捷键 | 作用 |
|---|---|
| `Super+D` | 打开控制台和应用菜单 |
| `Super+A` | 打开控制中心 |
| `Super+N` | 打开通知中心 |
| `Super+O` | 切换总览 |
| `Super+K` | 显示或隐藏屏幕键盘 |
| `Super+I` | 打开系统设置 |
| `Super+Shift+S` | 截屏并用手写笔批注 |
| `Super+Shift+N` | 快速便签 |

这些绑定写在 [`desktop-rust/niri/`](../desktop-rust/niri/) 的 Niri 配置里，可以按需修改。
