# 在 Waydroid 中运行原厂 ZUI

> 开发中。ZUI 18.5 已经能在容器中启动，并能用触控操作；其余功能还在完善，暂不适合日常使用。容器脚本还在频繁修改，暂未收入本仓库，稳定后发布。

## 是什么

[Waydroid](https://waydro.id/) 通常运行 LineageOS 镜像。这部分工作的目标是改用设备自带的 ZUI 系统镜像，让 Android 应用在 Linux 中运行时看到的环境尽量接近原厂系统。

系统镜像需要从你自己的设备中提取，本项目不分发任何 ZUI 文件。

## 做法

原版 ZUI 不是为容器构建的，主要的修改都在容器一侧：

- 切换到 ZUI 的 `system`、`vendor` 镜像，并修正它们在容器里启动时遇到的问题；
- 把 Waydroid 的触摸、鼠标、键盘事件转成虚拟输入设备，让原版 ZUI 能接收输入；
- 提供一个临时的 KeyMint 软件服务，让 ZUI 的密钥服务能启动；
- 让容器内看到的内核版本号与原厂一致。

## 内核要求

本项目的内核补丁和配置已包含 ZUI 容器需要的功能：

- SELinux（以 permissive 模式启用，容器无法把它切换为 enforcing）；
- dm-verity，供 ZUI 激活 APEX 模块；
- 容器内的内核版本号可以单独设置；
- BPF 对象按 PID 命名空间隔离，容器看不到宿主的 BPF 对象。

## 注意

**容器必须以只读方式挂载 `/sys`（LXC 的 `sys:ro`）。** ZUI 的初始化脚本会修改硬件设置，其中包括宿主的存储电源设置；`/sys` 可写时，曾导致平板休眠唤醒后存储无法恢复、根分区变为只读。Waydroid 默认的配置就是只读挂载，修改容器配置时不要改成可写。
